# BizFlow — Business Operations & Analytics Platform

BizFlow is a learning-focused project that explores how a small business management application can connect transactional software, relational databases, cloud data engineering, and business intelligence.

## Objectives

- Build a business application using C# and ASP.NET Core MVC.
- Design a relational database using SQL Server.
- Implement reliable transactional order processing and inventory management.
- Explore Entity Framework Core and database transaction management.
- Build an ETL/ELT pipeline using Azure Data Factory.
- Develop analytical models and dashboards using Power BI.

## Planned Technology Stack

- C# / ASP.NET Core MVC
- SQL Server
- Entity Framework Core
- Azure Data Factory
- Azure Data Lake Storage Gen2 (planned)
- Power BI
- Git and GitHub

## Planned Features

- Customer management
- Product and inventory management
- Order processing
- Transaction-safe stock updates
- Sales analytics and reporting

## Development Approach

BizFlow is being developed incrementally, beginning with C# and SQL fundamentals, domain modelling, database design, and transaction processing.

The initial application will be developed locally before selected components are introduced to Azure.
